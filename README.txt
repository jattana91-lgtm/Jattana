HOW TO GET THE APK
1. Create a free account at github.com and make a NEW repository.
2. Upload ALL files from this folder (keep the .github folder).
3. Open the "Actions" tab. "Build APK" runs automatically (about 3-5 minutes).
4. Open the finished run, scroll to "Artifacts", download "interest-calculator-apk" (zip).
5. Unzip it, copy app-debug.apk to your phone and install
   (allow "Install unknown apps" when asked).
